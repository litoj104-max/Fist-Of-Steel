# FistOfSteel

A lightweight Java action shooter made by a solo indie developer.

---

## 🎮 Controls

- WASD — Move
- Left Click — Shoot
- B — Build Mode
- 1 / 2 / 3 — Switch structures (Build Mode)
- R — Rotate structures
- V — Shop / Pause

---

## ▶️ How to Run

### Requirements
- Java JDK 21 (Amazon Corretto or similar)

### Run the game
Download the `FistOfSteel.jar` file and run:

```bash
java -jar FistOfSteel.jar
